# Flappy-Bird-
# 🐦 Flappy Bird AI-Synth

A high-performance, polished Flappy Bird clone built in seconds using **Kilo AI**. This project demonstrates the power of modern AI-driven development—moving from a raw prompt to a fully playable game with synthesized audio and physics in under 5 seconds.

---

## ⚡ The "5-Second" Challenge
This entire codebase was generated by **Kilo AI** in a single pass. By providing a high-context prompt, the AI-managed to architect:
* **Physics Engine:** Real-time gravity and terminal velocity calculations.
* **Procedural Generation:** Logic for infinite, randomized pipe obstacle spawning.
* **Audio Synthesis:** Zero-dependency sound effects generated via the Web Audio API.



## 🛠 Tech Stack
* **Language:** JavaScript (ES6+)
* **Rendering:** HTML5 Canvas API
* **Audio:** Web Audio API (OscillatorNode synthesis)
* **Styling:** CSS3 (Flexbox & Responsive design)
* **AI Engine:** Developed using **Kilo AI** Gateway

## 🚀 Key Features
* **Zero-Asset Audio:** All sound effects (Flap, Score, Hit) are generated mathematically via code. No `.mp3` or `.wav` files required, ensuring zero latency and no broken asset links.
* **Dynamic Animation:** Uses `requestAnimationFrame` for high-refresh-rate, 60FPS gameplay.
* **Mobile Responsive:** Fully playable on desktop (Spacebar) and mobile (Touch) via event listener optimization.
* **Visual Juice:** Integrated particle systems for "death" effects and a screen-flash mechanic to emphasize collision.
